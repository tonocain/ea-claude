# DISCOVERY OUTPUT
Process: Captación de clientes (prospección → pitch de diagnóstico)
Date: 2026-07-21

## Trigger (Start Event)
En una plática surge el nombre de un negocio desconocido; si le llama la atención a Antonio, arranca el proceso.

## End Result (End Event)
Tener un pitch completo listo para vender el diagnóstico.

## Participants / Lanes
- Antonio (dueño, único participante)

## Steps (ordered)
1. Scrapear la página del negocio | Responsible: Antonio | Type: user-system
2. Verificar alineación con el avatar (documento interno de Avatar y Oferta) | Responsible: Antonio | Type: manual
3. Preparar el pitch completo | Responsible: Antonio | Type: manual
3b. Enviar documento genérico + página de Project Krato, para que lo compartan con alguien más | Responsible: Antonio | Type: manual

## Decisions
- Después del paso 2: ¿El negocio se alinea con el avatar (PYME de servicios profesionales, salud privada, restaurantes/comida rápida, o agencias B2B; dueño-operador con procesos manuales pesados)? → si sí: pasa al paso 3 (preparar pitch completo) / si no: pasa al paso 3b (enviar documento genérico + página)

## Friction Points
- 🟡 Paso 3 (preparar el pitch): inseguridad al presentarlo y falta de una línea/estructura fija a seguir — se arma sin un método consistente.
