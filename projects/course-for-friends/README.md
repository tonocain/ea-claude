# Course for Friends — "Master Claude"

**Status:** Planning — full 6-session curriculum outlined, sessions 1-3 fully scripted point-by-point. Format is live/hands-on workshop, each friend building on their own project throughout. No start date set.

Antonio is building a hands-on course for 6-10 friends, sourced from his `curso-docs` knowledge base (Tribu Divisual vault) plus supplementary research for gaps not covered there. It's related to Project Krato but positioned as a standalone initiative.

**Purpose (all three at once):**
1. Favor — genuinely teach friends who want to learn.
2. Pilot — test the content/pacing before turning it into a paid Krato product.
3. Case studies — friends build something real, which becomes testimonial/portfolio material for prospects.

**Audience:** 6-10 friends, each working on their own real project/business throughout all 6 sessions (not a shared practice case) — maximizes the case-study value of purpose #3.

**Curriculum — 6 sessions, each ending in a hands-on deliverable on the friend's own project.** Full session scripts live in `sessions/`:

1. **Mentalidad + fundamentos de Claude Code** — intro to AI/LLMs (what it solves, where it falls short), Claude Cowork, Claude Code install + working modes. *(Scripted in full — `sessions/01-mentalidad-fundamentos-claude-code.md`; audience slide deck in `presentations/sesion-01-mentalidad-fundamentos.html` and a full-explanation student handout in `presentations/sesion-01-documento-repaso.html`, both styled with Claude's brand)*
2. **Skills** — anatomy of a `SKILL.md`, local vs global, the 6-step build framework, feedback cycle. *(Scripted in full — `sessions/02-skills.md`; audience slide deck in `presentations/sesion-02-skills.html` and a full-explanation student handout in `presentations/sesion-02-documento-repaso.html`, both styled with Claude's brand)*
3. **MCP servers** — MCP vs Skills (using the real `miro-bpmn` skill in this repo as the running example), setup, self-healing. *(Scripted in full — `sessions/03-mcp-servers.md`; audience slide deck in `presentations/sesion-03-mcp-servers.html` and a full-explanation student handout in `presentations/sesion-03-documento-repaso.html`, both styled with Claude's brand)*
4. **Automatización clásica** — webhooks, n8n (triggers, nodes, AI Agent, subworkflows, 17-node cheat sheet). Apify cut from scope. *(Outline only — `sessions/04-automatizacion-clasica.md`)*
5. **Agentic Workflows (WAT)** — why agentic now, the WAT framework, self-healing at build time, Plan Mode. "How to sell this" cut from scope. *(Outline only — `sessions/05-agentic-workflows-wat.md`)*
6. **Capstone — build your own EA** — the 4-phase Executive Assistant framework (Home/Life/Hands/Grow), applied live using everything from sessions 2-5. Scheduled Tasks/Loops folded in lightly here (the standalone deploy-to-production session covering Trigger.dev/Modal was cut entirely). *(Outline only — `sessions/06-capstone-ea.md`)*

**Source material:** `curso-docs` vault pages `05-claude-code`, `11-spec-driven-development`, `13-agentic-workflows-wat`, `14-mcp-servers`, `17-scheduled-tasks-vs-loops`, `18-asistente-ejecutivo-ia`, `04-webhook`, `10-guia-n8n` — plus Firecrawl research (Claude Cowork, Claude Design) for gaps the vault didn't cover, cited inline in the session files.
